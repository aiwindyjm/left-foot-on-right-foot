# 可复制的 Agent 执行规则

下列模板用于人类给 Coding Agent 分配仓库任务，不是机器协议消息。
替换方括号内容后使用；未来机器通道按 [协议](../protocol/README.md)发送 JSON。

```text
项目：左脚踩右脚 / Left Foot on Right Foot
阶段：[明确的 Phase]
目标：[本次唯一目标]
允许范围：[文件、行为与已批准操作]
禁止范围：[不可触碰的模块、外部服务与下一阶段]
验收：[可验证的完成标准]
停止条件：[完成、阻塞、重大决策、风险或限额]

1. 读取 AGENTS.md、README.md、当前阶段文档和相关规范。
2. 检查 Git 状态，识别并保留已有用户修改。
3. 读取相关代码或资料，说明本次边界，不擅自重构和升级阶段。
4. 仅完成当前任务。重大决策、破坏性操作或外发行为先请求 Human Gate。
5. 执行适用验证与测试，如实记录命令、退出状态和未验证范围。
6. 审查 diff、敏感信息与 Git 状态；仅在获得授权时提交或推送。
7. 输出下面的执行报告，然后停止，不自动领取下一阶段。
```

## 执行报告模板

```text
【TASK】阶段、任务、授权范围
【RESULT】已完成与未完成事项
【FILES】新增、修改、删除的文件
【VALIDATION】命令、真实结果、失败原因与未运行项
【RISKS】安全、兼容性和其他风险
【BLOCKERS】需要人工回答的问题；没有则明确写无
【GIT】分支、提交（如有）、工作区状态；不得编造远程成功
【STOP】完成 / 阻塞 / 人工门禁 / 错误 / 限额
【NEXT】建议下一步，不执行
```

若报告包含秘密或个人信息，先脱敏再传递。真实原文仅可在本地受控目录保留。
`REPORT` 中的验证结果 `NOT_RUN` 必须用于没有执行的检查，不能写 `PASS`。
