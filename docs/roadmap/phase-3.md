# Phase 3: More Adapters

目标版本：v0.3.0。状态：未实现。

入口：统一 Adapter 契约和单会话恢复机制稳定，接入目标分别获得批准。
范围：在Phase 1的Codex/ZCODE首批接入之上，按新批准范围扩展Claude Code、OpenCode及其他会话产品。
保持项目协调、产品会话、系统控制三层边界；扩展本地模型Provider，不绑定ChatGPT。
浏览器扩展或API会话须单独验证，不能替换用户指定的已有桌面对话；明确密钥、费用与数据边界，不自动获得调用授权。

验收：获准新增目标逐个通过共同契约测试和各自的隔离闭环验收；
不支持的能力明确报告，不在 Core 添加厂商分支；
文档分别列出支持版本、安装、能力限制和实际验证情况。
未完成全部目标时不得把 v0.3.0 描述为全部支持，范围调整须另行批准。
不做：同项目多执行者并发；首版已有的多项目独立循环不因此取消。出口：维护者验收并停止。
