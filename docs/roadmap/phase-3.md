# Phase 3: More Adapters

目标版本：v0.3.0。状态：未实现。

入口：统一 Adapter 契约和单会话恢复机制稳定，接入目标分别获得批准。
范围：Codex、Claude Code、OpenCode 的独立 Adapter；对每个工具先核实官方接口与权限。
LLM API 模式需单独明确密钥、费用与数据边界，不因支持多个 Agent 自动获得调用授权。

验收：三个目标逐个通过共同契约测试和各自的隔离闭环验收；
不支持的能力明确报告，不在 Core 添加厂商分支；
文档分别列出支持版本、安装、能力限制和实际验证情况。
未完成全部目标时不得把 v0.3.0 描述为全部支持，范围调整须另行批准。
不做：同时调度多个 Agent。出口：维护者验收并停止。
