# Roadmap

当前工作边界是 Phase 0。未来条目均为计划，不代表已经实现。
每阶段必须满足入口、出口并获得人类授权，不能由 Agent 自动升级阶段。

| 阶段 | 能力版本 | 文档 |
| --- | --- | --- |
| Phase 0 | Unreleased，不发布 | [Project Foundation](phase-0.md) |
| Phase 1 | v0.1.0 | [ZCODE ↔ ChatGPT PoC](phase-1.md) |
| Phase 2 | v0.2.0 | [Human Gate、Session、Recovery](phase-2.md) |
| Phase 3 | v0.3.0 | [更多 Adapter](phase-3.md) |
| Phase 4 | v0.4.0 | [Multi-Agent Workflow](phase-4.md) |
| Phase 5 | 未承诺，满足稳定性后考虑 v1.0.0 | [Agent Runtime](phase-5.md) |

发布日期由能力和验收决定，不预先承诺。
如果接入不可行，应暂停、提交证据并请求调整方向，不能静默换目标或降低安全要求。
