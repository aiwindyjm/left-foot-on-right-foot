# Phase 2: Human Gate + Session + Recovery

目标版本：v0.2.0。状态：未实现。

入口：PoC 的接入和安全边界已经验证；人类批准存储、隐私及恢复设计。
范围：完整人工审批交互、Session 持久化、受控原文审计、暂停继续、故障恢复。
数据默认本地保存，定义脱敏、访问、保留和删除策略，不自动上传遥测。

验收：断网、进程退出和重启后能恢复可核对状态；
未知派发结果必须人工核对，不能重复提交；批准绑定任务并在修改后失效；
可审计每次人工决策及状态变化，确认停止再恢复。
不做：多 Agent 编排或新厂商批量扩张。
出口：故障注入测试、存储迁移与隐私说明经维护者审查，然后停止。
