# Phase 0: Project Foundation

入口：读取两份原稿，确认 Git/账号状态，取得许可、身份、技术路线和公开发布授权。

范围：项目定位、架构、原稿保全、协议、状态机、规则、基础验证、Git 与 GitHub。
没有业务运行时；不得实现 Adapter、浏览器控制或 UI。

验收：

- 原稿逐字节保留，SHA-256 与归档清单一致。
- README 明确真实能力，开源许可及贡献、安全、行为和 Agent 规则完整可用。
- 协议有 Schema、动作正反例；状态机有进入、退出、错误和人工门禁规则。
- Phase 0–5 有边界与验收，不以目录数量代替能力。
- 本地基础验证与 Windows/Linux CI 通过；待提交内容无已发现的敏感信息。
- `main` 首次提交、公有仓库、上游跟踪和推送成功，远程提交与本地一致。
- 汇报真实结果与剩余问题，工作区干净。

停止：达到上述验收后立即停止。Phase 1 需要新的明确授权。
