## ZCODE：有官方事件接口，但闭环未证实

本次注册表显示已安装 **ZCode 3.12.3**，不同于审计时的3.11.2；官网当前下载版本也为3.12.3。
安装目录可见 Electron 程序和捆绑的内部脚本，但没有据此执行内部脚本或反编译安装包。
PATH 中此前未发现 zcode 不能等价于未安装，也不能等价于没有可用接口。

| 能力 | 已取得的依据 | 状态与限制 |
| --- | --- | --- |
| 会话标识 | 官方 Hooks 输入含 session_id、cwd、事件名 | 文档支持，未在用户隔离会话实测 |
| 工具证据 | PostToolUse 有结构化 tool_response，失败事件有 error | 值得做只读观察；不等于完整证据信任链 |
| 最后回复 | Stop 有 last_assistant_message；临时 transcript_path 在 Hook 完成后清理 | 可研究事件内采集，不能直接扫描历史目录 |
| 继续执行 | Stop 可返回 block 和反馈，最多连续3次 | 不是无限任务派发接口，也不证明支持异步等待规划完成 |
| 发送新任务和回执 | Remote Control 文档描述手机继续发指令 | 未发现本次可确证的公开第三方发送/回执契约 |
| 停止 | 原生界面有控制入口；Hook某些非零退出是可恢复失败 | 不可将Hook异常当成全局紧急停止；未实测停止回执 |
| MCP | 官方说明是 ZCODE 调用外部工具 | 不能推定外部系统可反向控制ZCODE |

官方 Hooks 文档说明用户/插件配置可用，项目级 Hook 当前不执行；修改配置后需新建 session。
没有擅自写入用户配置或安装 Hook。未来观察实验应单独审查插件，只回空结果，不写权限放行、修改工具输入或 Stop续跑反馈。
官方页局部设置说明提到workspace，但同页明确项目Hook不执行；以明确限制为调查基线，并需版本实测。
